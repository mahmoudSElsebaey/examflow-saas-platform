# دليل استخدام منصة ExamFlow — Assessment SaaS MVP

**منصة تقييمات واختبارات متعددة المستأجرين (Multi-tenant) للتعليم الحديث**

---

## 1. نظرة عامة وهدف الموقع

**ExamFlow** منصة SaaS تعليمية (EdTech) تمكن المدارس ومراكز التدريب والمعلمين من:
- إنشاء بنوك أسئلة واختبارات مؤقتة.
- تقديم الاختبارات للطلاب مع حفظ تلقائي.
- التصحيح التلقائي واليدوي.
- إصدار شهادات.
- تحليلات وتقارير.
- دعم كامل للعربي والإنجليزي مع RTL.

### الهدف:
حل دورة التقييم التعليمية كاملة داخل منتج واحد متعدد المستأجرين مع فوترة (Stripe أو Mock).

## 2. الأدوار والصلاحيات

## 3. دورة العمل التعليمية

1. **المؤسسة** تسجل وتدعو المعلمين والمصححين والطلاب.
2. **المعلمون** يبنون المنهج (مقررات → مواد → مواضيع → دروس) وبنوك الأسئلة.
3. **المعلمون/المصححون** يجمعون الاختبارات وينشرونها ويراقبون النزاهة.
4. **الطلاب** يدرسون الدروس ويؤدون الاختبارات المؤقتة (مع حفظ تلقائي).
5. **النظام** يصحح تلقائياً + طابور تصحيح يدوي للأسئلة القصيرة.
6. **النظام** يصدر شهادات ويرسل إشعارات ويفرض حدود الخطة عبر الفوترة.

كل شيء معزول حسب المؤسسة (Tenant).

---

## 4. دورة الطالب

1. تسجيل الدخول لحساب الطالب.
2. تصفح الدروس والمحتوى.
3. أداء الاختبار (مؤقت + حفظ تلقائي).
4. استلام النتيجة والشهادة (إن نجح).
5. التحقق العام من الشهادة برمز.

---

## 5. دورة المعلم / المالك

1. إنشاء منظمة أو الانضمام.
2. دعوة أعضاء.
3. بناء المناهج وبنوك الأسئلة (MCQ، صح/خطأ، إجابة قصيرة).
4. بناء الاختبارات (وقت، خلط، عدد محاولات).
5. نشر الاختبار ومراقبة الإشارات (فقدان التركيز، تبديل التبويب...).
6. تصحيح يدوي عند الحاجة.
7. عرض التحليلات وتصدير CSV.
8. إدارة الفوترة (Stripe أو Mock).

---

## 6. الميزات الرئيسية

- مصادقة كاملة (تسجيل، تحقق إيميل، نسيان كلمة المرور).
- منظمات متعددة المستأجرين + دعوات.
- مناهج كاملة (Courses → Subjects → Topics → Lessons).
- بنوك أسئلة متعددة الأنواع.
- محرك اختبارات مؤقت مع Autosave.
- إشارات نزاهة (Focus loss, Tab switch, Paste).
- شهادات قابلة للتحقق علناً.
- تحليلات + تصدير CSV.
- بحث داخل المنظمة.
- إشعارات داخل التطبيق + إيميل (Resend).
- فوترة Stripe أو وضع Mock.
- عربي + إنجليزي + RTL كامل.
- White-label جاهز (شعار + لون أساسي).
