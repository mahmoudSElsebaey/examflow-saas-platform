# خريطة استخدام ExamFlow

دليل عملي لفهم المنصة من أول تسجيل دخول حتى الشهادات. كل الحسابات التجريبية تستخدم كلمة المرور: **`Demo1234!`**

بعد تشغيل السيرفر نفّذ:

```bash
cd server && npm run seed
```

---

## 1) الفكرة العامة

ExamFlow منصة اختبارات متعددة المؤسسات (SaaS):

1. تسجّل حسابًا.
2. تنشئ **مؤسسة** (أكاديمية / مدرسة / مركز).
3. تضيف فريقًا (معلمين / مصححين / طلاب).
4. تبني **مقررات → مواد → مواضيع → دروس**.
5. تبني **بنوك أسئلة** ثم **اختبارات**.
6. الطالب يؤدي الاختبار، النظام يصحح تلقائيًا (ما عدا الإجابة القصيرة).
7. تُصدر **شهادة** قابلة للتحقق برابط عام.

اللغة: إنجليزي / عربي مع اتجاه RTL من مبدّل اللغة أعلى الصفحة.

---

## 2) الأدوار والصلاحيات

| الدور | ماذا يفعل |
|---|---|
| مدير المنصة `super_admin` | يرى كل المؤسسات، يوقف/يفعّل مؤسسة |
| المالك `owner` | كل شيء داخل المؤسسة + الأعضاء + الإعدادات + الفوترة |
| مدير `admin` | مثل المالك تقريبًا بدون نقل الملكية |
| معلم `teacher` | محتوى، بنوك، اختبارات، تصحيح، تحليلات |
| مصحح `examiner` | اختبارات وتصحيح وتحليلات |
| طالب `student` | تعلم، اختبارات متاحة، تقدمي، شهاداتي |

---

## 3) حسابات التجربة بعد الـ seed

| الحساب | الدور |
|---|---|
| `admin@demo.examflow` | مدير المنصة |
| `owner@demo.examflow` | مالك Demo Academy |
| `teacher@demo.examflow` … `teacher5@demo.examflow` | 5 معلمين |
| `examiner1@demo.examflow` … `examiner5@demo.examflow` | 5 مصححين |
| `student@demo.examflow` … `student8@demo.examflow` | 8 طلاب |

المؤسسة: **Demo Academy** (`demo-academy`) — خطة Professional.

البيانات المزروعة تقريبًا:

- 6 مقررات، 7 مواد، 8 مواضيع، 8 دروس
- 6 بنوك أسئلة، 24 سؤالًا
- 6 اختبارات (5 منشورة + 1 مسودة)
- محاولات للطلاب + شهادات + إشعارات + سجل نشاط

---

## 4) مسار الطالب (من الألف للياء)

1. ادخل بـ `student@demo.examflow`.
2. من لوحة التحكم افتح **Demo Academy**.
3. **التعلم**: تصفح المقرر → المادة → الموضوع → الدرس.
4. **الاختبارات**: ستظهر الاختبارات المنشورة. اضغط **بدء**.
5. أجب، النظام يحفظ تلقائيًا. سلّم عند الانتهاء.
6. تظهر النتيجة فورًا (ما لم تُؤجَّل). الإجابات القصيرة قد تنتظر تصحيحًا يدويًا.
7. إذا نجحت: اطلب/اعرض **الشهادة**. رمز التحقق مثل `DEMO0001`.
8. التحقق العام بدون حساب: صفحة `/verify/:code`.

---

## 5) مسار المعلم / المالك

1. ادخل بـ `owner@demo.examflow` أو `teacher@demo.examflow`.
2. **المقررات**: أنشئ مقررًا.
3. تبويب **المنهج**: مادة → موضوع → درس.
4. **بنوك الأسئلة**: بنك جديد ثم أسئلة (اختيار من متعدد / صح وخطأ / إجابة قصيرة).
5. **الاختبارات**: عنوان، مدة، نسبة نجاح، اختر الأسئلة، **نشر**.
6. **التصحيح**: طابور الإجابات القصيرة.
7. **الطلاب / الأعضاء**: دعوة بالبريد وتحديد الدور.
8. **التحليلات**: متوسط، نسبة نجاح، تصدير CSV.
9. **الشهادات**: عرض الصادر.
10. **الإعدادات**: الاسم، اللون، الشعار.
11. **الفوترة**: تغيير الخطة (وضع تجريبي بدون دفع حقيقي ما لم يُربط Stripe).
12. **البحث / النشاط**: بحث داخل المؤسسة وسجل التدقيق.

---

## 6) مسار مدير المنصة

1. ادخل بـ `admin@demo.examflow`.
2. من الهيدر: **إدارة المنصة**.
3. أرقام المستخدمين/المؤسسات/الاختبارات.
4. إيقاف أو تفعيل أي مؤسسة.

## 8) دورة الاختبار (مهم)

```
مسودة → إضافة أسئلة → نشر → الطالب يبدأ محاولة
→ حفظ تلقائي للإجابات → تسليم أو انتهاء الوقت
→ تصحيح تلقائي للاختيار من متعدد وصح/خطأ
→ تصحيح يدوي للإجابة القصيرة
→ نتيجة + شهادة عند النجاح
```

لا يمكن بدء محاولة لاختبار مسودة أو بدون أسئلة.

---

## 9) الإشعارات واللغة والـ Toast

- الجرس في الهيدر: نشر اختبار، نتيجة، شهادة، دعوة، طلب تصحيح.
- مبدّل اللغة يحفظ الاختيار ويقلب الاتجاه RTL للعربية.
- رسائل النجاح/الفشل تظهر كـ toast أعلى الشاشة (حفظ، نشر، دعوة، أخطاء الصلاحيات…).

---

## 10) ماذا تختبر أولًا؟

1. Seed ثم دخول owner وتصفح كل تبويبات المؤسسة.
2. دخول student وبدء اختبار منشور.
3. دخول examiner ومراجعة **التصحيح**.
4. فتح شهادة والتحقق بالرمز من صفحة عامة.
5. تبديل اللغة إلى العربية والتأكد أن القوائم والأزرار والحالات مترجمة.
6. دعوة عضو جديد من صفحة الأعضاء.
